# Interview Questions

Questions are grouped by level. Each answer is the one I'd want to hear as an interviewer, with code and output where it helps.
Click a question to expand its answer.

| Level | Typical experience | Focus |
|---|---|---|
| [Beginner](beginner.md) | 0–2 yrs | building blocks, CLI, binding, components, services, routing basics |
| [Intermediate](intermediate.md) | 2–5 yrs | RxJS, forms, HTTP, DI, change detection, lifecycle, testing |
| [Advanced](advanced.md) | 5–8 yrs | signals internals, zoneless, performance, SSR, security, architecture |
| [Expert & Scenarios](expert.md) | 8+ yrs / lead | system design, migrations, trade-offs, debugging war stories |
| [Coding Challenges](coding-challenges.md) | all | live-coding tasks with full solutions and output |

!!! tip "How to answer like a senior"
    1. **Definition** in one sentence. 2. **Why** it exists (the problem it solves). 3. **Code** or a real example.
    4. **Trade-offs** and gotchas. 5. **What you'd do in v22**.
