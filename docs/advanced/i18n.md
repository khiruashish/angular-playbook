# Internationalisation (i18n)

## Built-in i18n (`@angular/localize`): compile-time, one build per locale

```bash
ng add @angular/localize
```

```html
<h1 i18n="@@homeTitle">Hungry?</h1>
<input i18n-placeholder placeholder="Search restaurants" />
<span i18n>{count, plural, =0 {No items} =1 {One item} other {{{count}} items}}</span>
<span i18n>{veg, select, true {Pure veg} other {Serves non-veg}}</span>
```

```typescript
const msg = $localize`:@@orderPlaced:Order ${id}:id: placed!`;
```

```bash
ng extract-i18n --output-path src/locale --format xlf2   # messages.xlf → send to translators
```

```json title="angular.json"
"i18n": { "sourceLocale": "en-IN", "locales": { "hi": "src/locale/messages.hi.xlf", "ta": "src/locale/messages.ta.xlf" } },
"build": { "options": { "localize": true } }
```

```bash
ng build --localize      # dist/…/browser/en-IN, /hi, /ta
ng serve -c hi           # needs a per-locale serve configuration
```

!!! output "Output (hi build)"
    ```text
    <h1>भूख लगी है?</h1>
    ```

## Runtime alternatives

| | `@angular/localize` | Transloco / ngx-translate |
|---|---|---|
| Switch language | page reload / different URL | live, no reload |
| Performance | best (translations compiled in) | JSON loaded at runtime |
| Builds | one per locale | one |
| Best for | content sites, SEO per locale | apps with an in-app language switcher |

## Locale-aware pipes

```typescript
import { registerLocaleData } from '@angular/common';
import localeHi from '@angular/common/locales/hi';
registerLocaleData(localeHi);
providers: [{ provide: LOCALE_ID, useValue: 'hi' }, { provide: DEFAULT_CURRENCY_CODE, useValue: 'INR' }]
```

```html
{{ 1234567.5 | number }}    <!-- hi: 12,34,567.5 -->
{{ today | date:'fullDate' }}
```
